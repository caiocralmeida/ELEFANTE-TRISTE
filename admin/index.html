Armazenamento de imagens

As imagens são guardadas no Supabase Storage, no bucket game-media. Os arquivos do site permanecem no GitHub Pages.

Enquadramento independente

Para salvar imagens e enquadramentos diferentes na página inicial, loja e página do jogo, a migração sql/add-independent-image-framing.sql precisa estar aplicada no Supabase. O painel tenta preservar o salvamento básico se essas colunas ainda não existirem.

Não execute SQL novamente se já aplicou essa migração. O painel não altera seu banco de dados automaticamente.
